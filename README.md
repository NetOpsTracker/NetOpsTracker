# NetOps Tracker Lite

Internal ticket tracking tool. Runs entirely on the local machine.

## Install

Download and run `NetOps Tracker Lite Setup 1.0.1.exe`.

Installs per user under `%LOCALAPPDATA%\Programs`. No admin rights required.

The installer is unsigned, so Windows SmartScreen will show a warning. Choose **More info**, then **Run anyway**.

## Requirements

Windows 10 or 11, 64-bit.
